# ChekingRPC
Đây là ứng dụng check ping ( độ trễ ) của RPC trên onchain mạng robinhood

clone về, cập nhật tệp rpc  là xong 

**1. Setup version nodejs + npm**
```
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
```
```
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"
```
```
nvm install 22
nvm use 22
nvm alias default 22
```
**Check version**
```
node -v    # → v22.xx.x
npm -v     # → 10.xx.x
```
**2. CLone git**
```
git clone https://github.com/Apollo-Sync/checkpingrpc.git
```
